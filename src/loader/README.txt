DICE RUSH EXTENDED 1.1.1 - fan mod for DICE RUSH v1.0.0 (Full)
================================================================

INSTALL
-------
1. Copy "override.cfg" and the "DiceRushExtended" folder into the game folder
   (the folder that contains "Dice Rush.exe").
2. Start the game as usual. The main menu shows "Dice Rush Extended 1.1.1" at the
   bottom left and the HOST GAME / JOIN GAME buttons at the top right.

UNINSTALL
---------
Run "Uninstall Dice Rush Extended.bat" in the game folder (or delete "override.cfg"
and the "DiceRushExtended" folder). Your saves stay untouched.
Note: the original game cannot store more than 9.2e18 money, so a modded save with
more money shows wrong amounts without the mod. The mod's achievements are stored in
their own file (bdr_achievements.json); the original achievements are not changed.

EPILEPSY WARNING
----------------
This mod shows many bright, colourful effects that flash quickly one after another
(rolling dice, flashes, waves, rainbow and light effects - especially on full tables).
If you have epilepsy or are sensitive to flashing lights, do not use this mod.
If you feel dizzy or unwell while playing, stop playing immediately and talk to a doctor.

WHAT THE MOD ADDS
-----------------
- Performance: smooth even with thousands of dice (spatial grid, batched drawing,
  light-weight rolls, background warm-up). From 200 dice on, all dice get smaller so
  the table looks bigger.
- 500 more dice fit on the table: up to 7,000 dice.
- 100 new dice in 10 tiers (Pepe, 67, Twitch, YouTube, Pirate, Console, D&D,
  Lucky Block, Godot, Vault, Zombie, Racing Car, Tetris, Doge, Rickroll, Skibidi,
  Ohio and many more), each with its own effect. Big numbers up to 1dk (10^300),
  written as 1K, 1.1M, 1B, 1T ... 1aa, never "e".
- SHOP button: sell dice, unlock dice, 10 mouse and 10 table designs (looks only).
- Hold to buy: keep the buy button pressed and it buys faster and faster.
- Talent tree: 67 new talents (dice unlocks, more workers, worker training,
  13 dice families, selling, events, lucky cubes, tarot, staff, aura, chain power).
- Lucky cubes: levels for all new dice, 10 lucky-only dice, money bags, free dice,
  lucky streak (x2) and talent gold.
- Tarot: 40 new cards (minor arcana) with rarities. Only bought dice can be offered;
  better and more dice give better cards. Cards you already own are marked OWNED.
- 10 staff types: mechanic, janitor, chef, banker, merchant, mage, scientist, DJ,
  miner, monk.
- 9 new random events: meteor shower, coin rain, tornado, happy hour, rainbow,
  black cat, treasure chest, thief, lucky clover.
- 67 new achievements.
- Coop for 2 players.
- All mod texts in all 31 languages of the game.

COOP (2 PLAYERS)
----------------
Host:     click HOST GAME in the main menu. Your last save is loaded and the game
          waits for player 2. The coop button (next to the trophy) shows your IP
          addresses and can invite Steam friends.
Player 2: click JOIN GAME, enter the host's IP address and click CONNECT, or join
          through Steam (friends list -> "Join Game", or accept the invite).
Network:  LAN, Hamachi / Radmin VPN, or UDP port 47777 forwarded on the host.
Rules:    the game runs on the host. Player 2 plays on the same table with the same
          money and can roll, buy, sell and use talents, lucky cubes and tarot.
          Both players see each other's cursor (P1 / P2). Achievements are earned by
          the host.
